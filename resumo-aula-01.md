# Resumo da Aula 01: Apresentação da Disciplina e Contextualização

**Disciplina:** Frameworks Front-end (SENAI)
**Professor:** Prof. Me. Deivison S. Takatu

---

## 1. Contexto da disciplina

Hoje, boa parte das aplicações web modernas usa algum **framework front-end**. As empresas precisam de interfaces **rápidas, organizadas e fáceis de manter**. Por isso, o tema é tratado sob dois pontos de vista:

- **Requisito estratégico:** dominar o front-end é fundamental para a competitividade das empresas.
- **Arquitetura de software:** entender como as diferentes partes de um sistema se interligam para melhorar as aplicações.

## 2. O que é desenvolvimento front-end?

O **front-end** é a camada da aplicação com a qual o usuário interage diretamente. Ele é responsável por:

- criar as interfaces;
- organizar visualmente os elementos;
- garantir uma boa experiência do usuário (UX);
- comunicar-se com os sistemas que processam os dados (back-end / APIs).

## 3. Arquitetura de um site

Antes de programar, é preciso planejar:

- **Definição de escopo, prototipação e UX:** o que o site vai fazer e como será a experiência.
- **Importância no desenvolvimento web e UX/UI:** um bom planejamento evita retrabalho.
- **Validação de ideias e iteração:** protótipos permitem testar e refinar a usabilidade antes da versão final.
- **Ferramentas:** uso de softwares de prototipação e de gestão de projetos.

## 4. Versionamento e deploy

- **Versionamento (Git/GitHub):** registra o histórico de alterações do código, permite trabalhar em equipe, criar *branches* e voltar a versões anteriores.
- **Deploy:** publicar a aplicação na web para que outras pessoas possam acessá-la. Na disciplina usamos o **Vercel**, que publica o site automaticamente a cada `push` no GitHub.

## 5. Introdução ao JavaScript (Vanilla JS)

| Conceito | Descrição |
|---|---|
| **O que é** | Linguagem de script interpretada, essencial para o desenvolvimento front-end. |
| **Vanilla JS** | JavaScript puro, sem bibliotecas ou dependências externas. É a base de todas as abstrações (frameworks). |
| **Importância** | Permite manipular as páginas (DOM), comunicar-se com servidores e implementar a lógica da interface. |

## 6. Introdução a frameworks front-end

- **Conceito, importância e benefícios:** frameworks oferecem estrutura pronta, padrões e produtividade.
- **Principais frameworks e bibliotecas:** **React**, **Vue** e **Angular**.
- **Arquitetura e componentização:** a interface é dividida em **componentes** reutilizáveis, o que organiza o código.
- **Estado, rotas e gerenciamento de dados:** controle do estado da aplicação, navegação entre páginas (roteamento) e integração com APIs.

## 7. O que estudaremos no semestre

- Ambiente de desenvolvimento;
- Frameworks CSS e front-end;
- Componentes e interfaces;
- Boas práticas;
- Deploy de aplicações.

**Objetivo:** ao final do semestre, ser capaz de desenvolver interfaces modernas, criar aplicações com frameworks front-end, utilizar Git e GitHub e publicar aplicações na web.

## 8. Metodologia de ensino

- Aulas expositivas dialogadas;
- Discussões para estimular o pensamento crítico;
- Estudos de caso e cenários industriais;
- Conexão entre teoria, prática e experiências profissionais.

## 9. Critérios de avaliação

| Item | Peso |
|---|---|
| **Avaliação docente** | **55%** |
| ↳ Desenvolvimento do projeto | 20% |
| ↳ Apresentação do projeto | 20% |
| ↳ Realização das atividades | 15% |
| **Projeto Integrador** | **35%** |
| **Autoavaliação** | **10%** |

- **Desenvolvimento do projeto:** documentação completa, como um "mini TCC", cobrindo planejamento, execução, resultados, desafios, soluções adotadas e análise crítica.
- **Apresentação do projeto:** foco no processo de gestão (organização do backlog), nas páginas desenvolvidas e na análise de *benchmarking* em comparação com soluções do mercado.

> **Dica:** manter um **portfólio de projetos** demonstra habilidades práticas, serve como evidência do aprendizado e amplia as oportunidades de estágio e emprego.

## 10. Atividades da aula

- **Atividade 01:** criar um projeto em Vanilla JS (HTML, CSS e JavaScript), conectar a IDE ao GitHub e fazer o deploy no Vercel.
  - Projeto entregue: **Jogo da Forca**, disponível em <https://vanilajsref.vercel.app>.
- **Atividade 02:**
  1. Formar grupos de 3 a 5 integrantes (a mesma composição para as atividades semanais);
  2. Criar um repositório no GitHub para as atividades do semestre, contendo este resumo da Aula 01;
  3. Escolher um framework front-end e elaborar um relatório técnico em PDF (mínimo de 5 páginas) com características, vantagens, aplicações no mercado e um exemplo de uso em um projeto web.
